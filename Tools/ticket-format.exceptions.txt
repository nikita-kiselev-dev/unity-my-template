# Исключения Tools/ticket-format.ps1.
# Формат строки: <тикет>:<правило> # <причина>
# Причина обязательна: строка без неё считается ошибкой скрипта, а не разрешением —
# иначе файл превращается в свалку и конвенция размывается второй раз.
#
# Пример:
# UMT-Bug-N:related-module-mismatch # баг на стыке двух модулей, статьи второго ещё нет
