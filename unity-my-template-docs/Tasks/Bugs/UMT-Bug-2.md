# AGENTS.md обрезается и не включает архитектурные правила

## Симптом

Корневой `AGENTS.md` занимает больше стандартного лимита Codex 32 KiB и загружается только до
середины раздела TDD. Архитектурные правила после него агент не получает. Описанные Stop-хуки
зарегистрированы только для Claude Code, а приёмочный текст требует недоступный в части агентов
инструмент `AskUserQuestion`.

## Воспроизведение

Сравнить размер `AGENTS.md` с 32 KiB и декодировать первые 32768 байт: текст заканчивается около
строки 181. В репозитории есть `.claude/settings.json`, но нет `.codex/hooks.json`.

## Причина

`AGENTS.md` стал копией архитектурного vault вместо короткого always-loaded контракта. Детали
хуков привязаны к конфигурации и имени инструмента Claude Code, хотя сами PowerShell-обёртки
совместимы с контрактом Stop-хуков Codex.

## Решение

- Оставить в `AGENTS.md` только всегда нужные guardrails, порядок работы, проверки и точные
  контекстные указатели на vault.
- Добавить один последовательный Stop-hook Codex: отдельные обработчики Codex запускает
  параллельно, а проектная цепочка зависит от порядка.
- Сформулировать приёмочный вопрос через доступный агенту механизм выбора с plain-text fallback.
- Синхронизировать статьи `Hooks` и `Tickets` с поддержкой Claude Code и Codex.
