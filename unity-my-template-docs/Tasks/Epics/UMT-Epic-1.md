# Шаблон. Epic: тема одним предложением

Скопируй файл в `UMT-Epic-N.md` (`N` = max существующего + 1). Этот файл не
переводи в `In Progress` и не правь под живую задачу. Подтикеты — обычные
`UMT-Feature-N` / `UMT-Bug-N` с полем `epic: "[[UMT-Epic-N]]"`; в этом файле
ручной список работ, которые **ещё не** вынесены в подтикеты.

## Цель

Каждая новая Model/ViewModel/сервис с логикой появляется test-first, и это
проверяет машина, а не дисциплина агента.

## Проблема

```
Сейчас: тесты пишутся вместе с реализацией или после неё; красной фазы нет,
        гейт tdd-check либо молчит (исключения), либо ловит уже после факта.
Хочу:   красный прогон на ассерте зафиксирован в журнале до зелёного;
        выживший мутант на границах разбирается в том же тикете.
Почему: без красной фазы тест подтверждает, что код исполняется, а не что
        поведение зафиксировано; через месяц это невидимо.
```
