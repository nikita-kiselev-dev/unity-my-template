# Agent Navigation

## Для агента

Эта статья отвечает на вопрос: какую документацию открыть первой. Не используй её как источник деталей; после выбора направления переходи в конкретную статью.

Перед рабочей задачей проверь связанный тикет в `Tasks/Features/`, `Tasks/Bugs/` или `Tasks/Epics/`. Если тикета нет, сначала создай его по конвенции [[Tickets]]; перед активной работой переведи в `In Progress`.

Перед изменениями прочитай в релевантной статье секции `Для агента`, `Инварианты`, `Как расширять` / `Как добавить` и `Когда обновлять`.

Статья с `status: stub` — заглушка: она годится как цель `related:` тикета, но не как источник истины. Детали такой подсистемы бери из кода и из выжимки в `AGENTS.md`.

## Как читать статьи

1. Найди статью по задаче.
2. Открой `source_paths` из frontmatter, если задача затрагивает код из этих файлов.
3. Сверь документацию с текущим кодом.
4. Если меняешь поведение из статьи, обнови статью в том же изменении.

## Сигналы устаревшей статьи

- В `source_paths` изменился публичный контракт или lifecycle.
- В коде появился новый обязательный шаг, которого нет в рецепте.
- Секция `Инварианты` противоречит текущей реализации.
- Новая фича копирует паттерн, но в документации нет актуального примера.
